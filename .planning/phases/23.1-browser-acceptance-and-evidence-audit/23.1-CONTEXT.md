# Phase 23.1 Context: Browser Acceptance & Graph Evidence Validation

## Background & Intent
Phase 23 delivered the initial Standards Knowledge Graph endpoint set and React+D3 visualization.
Phase 23.1 independently validates and audits these claims against:
1. Strict API contract robustness (boundary tests, malformed inputs, edge cases).
2. Live interactive browser verification (search, hubs, inspector drawer, pan/zoom, mobile layout, disclaimer).
3. Authoritative graph coverage and evidence quality audit (catalogue vs curated DB, missing evidence/clauses, identifier consistency).
4. Safety invariants (zero impact on tender recommendations, ranking thresholds, or ground-truth integrity).

## Locked Decisions
- Read-only graph exploration. Zero mutations to recommendations or ground-truth dataset.
- Never label relationships `VERIFIED` unless backed by official BSB Edge / portal records.
- Fix confirmed defects with deterministic regression tests.
- Produce comprehensive audit report in `docs/evaluation/PHASE23_1_BROWSER_ACCEPTANCE_AND_EVIDENCE_AUDIT.md`.
