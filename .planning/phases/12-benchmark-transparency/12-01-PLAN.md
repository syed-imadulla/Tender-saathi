# Plan 12-01: Ground-Truth Schema & Provenance Audit

**Phase**: 12 (Benchmark Transparency, Ground-Truth Quality, and Source Provenance)  
**Plan ID**: `12-01`  
**Focus**: Schema Extension, Provenance Binding & Data Transparency  
**Dependencies**: None (First plan in Phase 12)

---

## 1. Objective

Audit the existing 20-row benchmark dataset in `dataset/ground_truth/ground_truth.csv`, extend its schema with non-breaking provenance and adjudication metadata columns, bind every test case to its original source tender document and page in `tenders/raw/`, and preserve genuine verification status (`human_verified: FALSE` across all unadjudicated rows).

---

## 3. Tasks & Concrete Deliverables

1. **Schema Extension (BENCH-01)**:
   - Add columns: `source_document`, `procurement_sector`, `expected_decision`, `adjudication_status`, `reviewer_role`, `reviewed_at`.
   - Maintain 100% backward compatibility for existing pandas and csv parsers.
2. **Provenance Binding (BENCH-02)**:
   - Map each tender identifier (e.g., T001, T002, T003, ..., T020) to its physical PDF/text file in `tenders/raw/` (or mark `UNARCHIVED_EXTERNAL_TENDER` if sourced from external public eProcurement portal with portal URL in `evidence_source`).
   - Assign accurate procurement sector tags (`CPWD_CIVIL`, `NUCLEAR_PROCESS_PIPING`, `ELECTRICAL_SUBSTATION`, `SANITARY_SEWERAGE`, etc.).
3. **Audit & Adjudication Status (BENCH-03)**:
   - Ensure all 20 rows are explicitly tagged with `adjudication_status: UNADJUDICATED` and `human_verified: FALSE`.
   - Ensure `reviewer_role: UNASSIGNED` and `reviewed_at: ""` for all unadjudicated rows.
4. **Automated Provenance Validator**:
   - Write `scripts/audit_ground_truth_provenance.py` that validates all 20 rows, checks standard catalogue presence, and outputs a structured Markdown report.

## 4. Acceptance Criteria

- [ ] `dataset/ground_truth/ground_truth.csv` contains all 18 original columns in exact sequence, plus 6 appended metadata columns.
- [ ] No row has `human_verified == TRUE` without genuine expert sign-off.
- [ ] Every row has a non-empty `source_document` or documented portal reference.
- [ ] Existing test suites (`tests/test_evaluation_benchmark.py`, `pytest -q`) continue to pass without errors.
- [ ] Automated regression tests in `tests/test_ground_truth_integrity.py` pass cleanly offline.
