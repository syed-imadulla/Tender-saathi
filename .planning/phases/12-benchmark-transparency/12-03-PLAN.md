## 1. Objective

Build an automated candidate extraction and expansion pipeline that parses raw procurement tenders from `tenders/raw/` into candidate benchmark cases explicitly labeled `adjudication_status: MACHINE_PREDICTED`, and install a strict CI governance gate that permanently blocks synthetic or unverified claims of human expert adjudication.

## 3. Tasks & Concrete Deliverables

1. **Candidate Expansion Pipeline (EXP-01)**:
   - Extract raw text/tables from unparsed tenders in `tenders/raw/` (`eProcurement System Government of India.pdf`, `2.pdf`, `3.pdf`, `4.pdf`, etc.).
   - Run offline extraction and heuristic recommendation to generate candidate ground truth proposals.
   - Enforce:
     - `adjudication_status = "MACHINE_PREDICTED"`
     - `human_verified = False`
     - `reviewer_role = "UNASSIGNED"`
     - `reviewed_at = ""`
   - Save candidate proposals to a separate staging file: `dataset/ground_truth/candidates_staging.csv` so the primary benchmark is never automatically contaminated.
2. **Anti-Falsification CI Governance Gate (GATE-01)**:
   - Add automated test `test_anti_falsification_guard` in `tests/test_ground_truth_integrity.py`.
   - Assert:
     - Any row with `human_verified == True` MUST have:
       1. `adjudication_status == "EXPERT_VERIFIED"`
       2. A non-empty, recognized `reviewer_role` (e.g. `CPWD_ENGINEER`, `BIS_STANDARDS_OFFICER`, `PROCUREMENT_EXPERT`).
       3. A valid ISO timestamp in `reviewed_at`.
       4. A non-empty `evidence_reference` and `evidence_snippet`.
     - Reject with test failure if any row violates these criteria.
3. **Adjudication Standard Operating Procedure**:
   - Write `docs/data/GROUND_TRUTH_GOVERNANCE.md` detailing:
     - How procurement engineers review staged candidate rows.
     - Verification checklist (standard applicability, scope clause confirmation, QCO currency).
     - Signed adjudication recording format.
