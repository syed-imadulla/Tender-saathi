### Critical Discrepancies & Audit Findings Flagged

1. **Adversarial Architecture**:
   - The adversarial suite is structured as **14 failure categories** (5 probes each = 70 probes) evaluated across **8 multi-dimensional metrics** (False-Positive Rejection, Unsafe Confident Rec, Safe Abstention, Evidence Grounding, Lifecycle Trap Catch, Human-Review Recall, Prompt Injection Containment, Crash-Free Rate). Both views must be documented clearly.
2. **Canonical Relationship Taxonomy**:
   - Source code in `src/standards.py` defines **8 canonical relationship types** (`NORMATIVE_REFERENCE`, `TEST_METHOD`, `INSTALLATION_CODE`, `SAFETY_STANDARD`, `TERMINOLOGY_STANDARD`, `ALLIED_STANDARD`, `SUPERSEDES`, `AMENDS`). Documentation will document all 8 types.
3. **Lexical Retrieval Stack**:
   - Existing `README.md` erroneously claims BM25 is powered by the `rank_bm25` package. `src/bm25_search.py` is a custom, zero-dependency, pure-Python implementation. The documentation will correct this.
4. **Duplicate Tender PDF Locations**:
   - Both `tenders/raw/*.pdf` and `data/tenders/*.pdf` contain the exact same 20 government PDFs.
   - **Crucial finding**: `tests/test_p7b_api_ui_contract.py`, `tests/test_p7c_evidence_chain.py`, and `scripts/validate_e2e.py` actively query `tenders/raw/`. `scripts/demo.py` and `tests/test_milestone2.py` actively query `data/tenders/`.
   - **Decision**: **NEITHER will be deleted**. Both directories must be preserved to prevent breaking active test suites.
5. **Stale Empty Database**:
   - `data/standards.db` (root of `data/`) has 0 tables and 0 bytes, and 0 code references. The real database is `data/standards/standards.db`.
   - **Decision**: Flagged for archival or ignore, but do not delete until user review.
6. **Committed Ephemeral Reports**:
   - Over 1,570 `reports/generated/ts-*` test session files and 81 `data/catalogue/manifests/manifest_snapshot_*` files were committed in commit `9ef3930`.
   - **Decision**: Add `.gitignore` rules for new runtime files. Do NOT delete tracked sample reports (`sample-cpvc_*`, `sample-valve_*`, `sample-superseded_*`).
