# Plan 13-01: Reviewer Case Packet Generator & Adjudication Rubric Specification

## 1. Objective

Provide a rigorous, self-contained adjudication framework for external standards and procurement engineers. This includes:
1. Publishing `docs/data/ADJUDICATION_RUBRIC.md` containing the definitive adjudication criteria for the 5 canonical decisions (`RECOMMEND`, `ABSTAIN_UNDER_SPECIFIED`, `ABSTAIN_AMBIGUOUS`, `ABSTAIN_CONFLICTING`, `REJECT_INELIGIBLE`).
2. Creating `scripts/generate_adjudication_packets.py` to compile comprehensive case packets containing source PDF references, exact requirement text, current system predictions, candidate BIS standards with scopes, and structured adjudication reply templates.
3. Generating 40 case packets in `reports/adjudication_packets/` covering:
   - 20 Active Benchmark Cases (`dataset/ground_truth/ground_truth.csv`, currently `UNVERIFIED_BASELINE`).
   - 20 Staged Candidate Cases (`dataset/ground_truth/candidates_staging.csv`, currently `MACHINE_PREDICTED`).

---

## 2. Technical Context & Constraints

- **Source Traceability**: Every packet must identify the source PDF in `tenders/raw/`, the exact tender notice ID, page number, and surrounding context.
- **Decision Vocabulary**: Only the canonical vocabulary defined in `13-CONTEXT.md` is permitted.
- **Zero Fabrication**: Packets must leave reviewer name, signature, timestamp, and final consensus decision blank, waiting for human adjudication.

---

## 3. Implementation Steps

1. **Rubric Documentation (`docs/data/ADJUDICATION_RUBRIC.md`)**:
   - Explicit definitions and flowcharts for each of the 5 canonical decisions.
   - Evidence standard: Mandatory BIS Clause number and verbatim scope excerpt for every positive recommendation.
   - Conflict resolution procedure for divergent reviews.

2. **Packet Generation Tool (`scripts/generate_adjudication_packets.py`)**:
   - Ingests `ground_truth.csv` and `candidates_staging.csv`.
   - Cross-references `tenders/raw/` to ensure verifiable document linkage.
   - Ingests SQLite catalogue `standards.db` to pull official standard title, status, and scope for all candidate standards.
   - Formats clean, standardized Markdown packets into `reports/adjudication_packets/`.

3. **Output Generation**:
   - Generate `reports/adjudication_packets/packet_manifest.json`.
   - Generate all 40 individual case packet files (`CASE_T001_R002.md`, etc.).

---

## 4. Acceptance Criteria

- [ ] `docs/data/ADJUDICATION_RUBRIC.md` exists and covers all 5 decisions with concrete examples.
- [ ] `scripts/generate_adjudication_packets.py` runs without network dependencies.
- [ ] Exactly 40 reviewer packets are generated with complete provenance data and blank reviewer sign-off sections.
- [ ] Automated validation confirms zero fabricated reviewer approvals.
