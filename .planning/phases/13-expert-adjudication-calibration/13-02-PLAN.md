# Plan 13-02: Adjudication Ingestion, Two-Party Consensus Tool & Governance Enforcer

## 1. Objective

Build an automated, tamper-resistant ingestion and consensus verification CLI (`scripts/ingest_adjudication.py`) that:
1. Ingests completed reviewer packets from `reports/adjudication_packets/completed/`.
2. Validates reviewer role, credentials, ISO-8601 timestamps, evidence clause citations, and rationale against `GATE-01`.
3. Compares independent adjudications from Reviewer A and Reviewer B to establish two-party consensus.
4. Detects disagreements, flags them for senior adjudication, and prevents disputed cases from entering active ground truth.
5. Safely stages consensus-verified cases into `dataset/ground_truth/verified_staging.csv` with dry-run capabilities.

---

## 2. Technical Context & Constraints

- **Governance Rules**: Must strictly enforce rules in `docs/data/GROUND_TRUTH_GOVERNANCE.md`:
  - `human_verified` may only become `TRUE` if `adjudication_status == 'EXPERT_VERIFIED'`.
  - Non-empty `reviewer_role` conforming to approved engineering titles.
  - Valid `reviewed_at` timestamp.
  - Minimum 20-character substantive reasoning explaining why the standard applies or why abstention is mandatory.
- **Fail-Safe Integrity**: Active `dataset/ground_truth/ground_truth.csv` must NEVER be modified unless consensus verification passes 100% of validation gates.

---

## 3. Implementation Steps

1. **Ingestion Engine (`scripts/ingest_adjudication.py`)**:
   - Parse YAML frontmatter or structured markdown tables from completed packets.
   - Extract primary reviewer decisions, secondary reviewer decisions, consensus status, and evidence citations.
2. **Consensus Validator**:
   - Compare `decision_A` vs `decision_B` and `standards_A` vs `standards_B`.
   - If match: mark `consensus_status: REACHED`.
   - If mismatch: mark `consensus_status: CONFLICT_ESCALATION` and withhold from promotion.
3. **Staging & Promotion CLI**:
   - Provide `--dry-run` flag to display validation results without disk writes.
   - Output clear audit logs of all processed and rejected packets.

---

## 4. Acceptance Criteria

- [ ] `scripts/ingest_adjudication.py` passes all unit tests in `tests/test_adjudication_workflow.py`.
- [ ] Tool correctly identifies consensus agreements, single-reviewer incompleteness, and reviewer conflicts.
- [ ] Tool blocks any packet with missing reviewer role, missing timestamp, or missing evidence snippet.
- [ ] Tool preserves byte-level integrity of existing active `ground_truth.csv`.
